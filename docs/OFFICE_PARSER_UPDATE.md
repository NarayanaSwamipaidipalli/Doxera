# Re-enabling Office and XML imports

RC2 disables Word, Excel and PowerPoint uploads and the HTML renderer, which accepts inline SVG. The web catalog and converter both enforce this restriction. PDF-to-Office tools accept PDF inputs and generate their own Office output.

1. **Inventory each parser.** Capture the Docker base digest, Debian source and binary versions for Expat, libxml2 and LibreOffice, Python's `pyexpat.EXPAT_VERSION` and lxml's compiled and runtime libxml2 versions. Use `ldd` on LibreOffice's `libmergedlo.so` and inspect native bindings during a benign DOCX export. The reviewed image used Expat 2.9.0, a Debian libxml2 based on 2.9.14, and a separate libxml2 2.14.6 in lxml.
2. **Choose a supported patch for each copy.** Prefer a stable Debian security update or verified backport. On 22 November 2026 Debian marked trixie's `2.9.0-1~deb13u1` vulnerable to CVE-2026-115506 and `2.10.0-1` in forky/sid fixed. It marked `2.15.4+dfsg-1` fixed for CVE-2026-86138 in those suites. Check CVE-2026-6653 and the remaining applicable XML advisories separately. If stable fixes are unavailable, test a complete, supported replacement base with a compatible LibreOffice build. Mixing unstable libraries into trixie risks ABI incompatibility. [Debian Expat tracker](https://security-tracker.debian.org/tracker/CVE-2026-115506) · [Debian libxml2 dictionary tracker](https://security-tracker.debian.org/tracker/CVE-2026-86138) · [Debian libxml2 entity tracker](https://security-tracker.debian.org/tracker/CVE-2026-6653)
3. **Refresh Python and the native importer.** Upgrade or rebuild CPython if its pyexpat module embeds an affected engine. Upgrade lxml to a compatible wheel, or rebuild it against the approved library if its bundled version is affected. Rebuild the image, verify the actually loaded versions and capture vendor backport evidence. Update the package and license inventories.
4. **Harden all XML entry points.** Reject unsupported DTDs and external entities before parsing user-supplied package XML. Preserve checks on upload bytes, expanded ZIP content, entry counts, runtime and converter network access. Review optional embedded fonts, XML and media for each enabled format.
5. **Restore tools individually.** In a test branch, exercise each importer in the 2 GB image using known DOCX, XLSX and PPTX fixtures. Extract expected text from the downloaded PDFs. Test mislabelled formats, invalid manifests, timeouts and deletion. Review the HTML/SVG renderer separately. Rerun the 24 working workflows and all safeguards. Keep the password gate during hosted synthetic verification. Tag the newly approved build and retain RC2 for rollback.
